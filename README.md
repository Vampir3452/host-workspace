# За кулисами

Личное рабочее пространство ведущего. Google Календарь задаёт мероприятия и их время; сайт хранит описание, быстрые заметки, вопросы обсуждения, задачи подготовки и ссылку на сценарий в Google Документах.

Это самостоятельный статический проект для GitHub Pages. Другие сайты в родительской папке ему не нужны. Серверная функция и SQL находятся в `supabase/` и разворачиваются отдельно в твоём Supabase.

## Локальный запуск

Нужен Node.js 22 или новее. Установка npm-пакетов не требуется.

```powershell
node scripts/serve.mjs
```

Открой `http://localhost:4180/`. Кнопка просмотра примера открывает демонстрационные события с вымышленными данными. Они хранятся отдельно от рабочего аккаунта. Рабочая синхронизация требует настроенного Google OAuth и серверной функции календаря.

```powershell
node --test tests/*.test.mjs
node scripts/build.mjs
```

В `dist/` попадают только публичные файлы приложения. Пароли, SQL, серверная функция, документация и тесты в сборку не включаются.

## Подключение

Следуй [SETUP.md](./SETUP.md): база Supabase, вход Google, доступ к календарю, серверная функция и GitHub Pages. Публичные Project URL и Publishable key уже записаны в `config.js`; сами по себе они не создают таблицы и не включают Google OAuth.

Схема базы и политики доступа уже применены в указанном проекте Supabase: данные защищены RLS, список владельцев хранится в закрытой схеме. Это не означает, что Google OAuth и серверная интеграция календаря уже подключены; их нужно проверить отдельно.

## Правила работы

- Импортируются только заголовки с `Заказ:` и `?Заказ:` в начале. `?Заказ:` — неподтверждённое мероприятие.
- Название, дата, время и площадка приходят из Google Календаря. Перенос события сохраняет его рабочие материалы.
- Быстрые заметки — единый блокнот. Вопросы обсуждения и задачи подготовки редактируются независимо от общего шаблона.
- Шаблоны «Свадьба», «День рождения», «Корпоратив» изначально пустые: их содержание разрабатывается отдельно. «Другое» не применяет шаблон.
- Сценарий открывается по HTTPS-ссылке на Google Документ. Автоматического копирования документа на сайт нет.
- Удалённое из календаря событие сохраняет материалы с отметкой удаления.
- Изменения сохраняются локально и отправляются в Supabase при доступной связи. Конфликты требуют выбора версии; автоматической скрытой перезаписи нет.
- На одном устройстве редактирование доступно в одной вкладке: дополнительная вкладка показывает, что кабинет уже открыт. Продолжай работу в первой вкладке или закрой её перед переключением.

## Без интернета

Заранее открой сайт и нужные карточки на том устройстве, которое берёшь с собой. Дождись сохранения. На телефоне и компьютере отдельные локальные хранилища; ещё не загруженные события без сети не появятся. После первой загрузки оболочка сайта сохраняется через service worker. Обновление оболочки применяется после закрытия старых вкладок.

При локальной разработке на `localhost` и `127.0.0.1` публичные файлы сначала загружаются с сервера, а без связи открывается сохранённая оболочка. На опубликованном сайте используется сохранённая версия до безопасного обновления; API и данные аккаунта service worker не кэширует.

Офлайн-доступ к сценарию настраивается отдельно в Google Документах. Очистка данных браузера удаляет локальные копии и ещё не синхронизированные изменения. Пользуйся собственным устройством.

## Резервные копии

Периодически скачивай копию карточек и шаблонов из раздела резервного копирования. В ней только текстовые материалы и ссылки на сценарии, без Google Документов, паролей и токенов. Сохраняй файл в надёжном месте: в нём могут быть контакты и сведения о заказчиках. Перед восстановлением показывается перечень добавлений и изменений.

## Бесплатные сервисы

Подписок проект не требует. У бесплатных сервисов есть ограничения: Supabase может приостановить малоактивный проект; в это время облачная синхронизация не работает. Сохранённые на устройстве карточки остаются доступны. Google также может потребовать повторное подключение аккаунта после отзыва или истечения разрешения. Актуальные условия: [Supabase Free](https://supabase.com/pricing), [приостановка проектов](https://supabase.com/docs/guides/platform/free-project-pausing).

## Структура

| Файл | Назначение |
| --- | --- |
| `app.js`, `styles.css`, `index.html` | Интерфейс |
| `lib/model.js` | Правила импорта, шаблоны, проверка резервных копий |
| `lib/storage.js` | Локальные данные в IndexedDB |
| `lib/api.js` | Вход и работа с Supabase |
| `sw.js` | Офлайн-оболочка без кэширования API |
| `supabase/migrations/` | Таблицы, права доступа и защита от конфликтов |
| `supabase/functions/google-calendar/` | Чтение календаря и обновление Google-токена на сервере |
| `scripts/`, `tests/` | Запуск, сборка и проверки |
