# Локальный мост Codex

Мост запускается на компьютере владельца кабинета и использует авторизацию установленного Codex CLI. Он принимает запросы только с личного сайта и localhost, слушает только `127.0.0.1`, требует случайный ключ из окна запуска и не публикует его.

Для запуска открой PowerShell в папке проекта и выполни:

```powershell
node bridge/server.mjs
```

Codex CLI должен быть установлен и авторизован через текущий аккаунт. Оставь окно запущенным, пока используешь чат. Ключ появится в этом окне; вводи его только в своём браузере. Остановить мост можно сочетанием Ctrl+C.

Команды выполняются в корне этого проекта с режимом `workspace-write`: Codex может менять файлы проекта. Публикация на GitHub Pages сама по себе не происходит.
